# Local parity charges cannot resolve Rule 30 by conservation alone

Troy Lowry, with OpenAI Codex

**Draft for human review. Partial result, not a solution of a prize problem.**
The headline is `Rule30Submission.paired_F2_exact`: for every positive window
width, any mod-two local score mixing two coordinatewise Rule 30 histories is
conserved under four updates on all closed input walks exactly when it is a
constant plus a spatial coboundary. The proof also permits any family of
Boolean coordinates. No width bound or finite-ring census is a premise.

## The question

Rule 30 is `left XOR (center OR right)`. Problem 1 asks whether the center
from one black cell is not eventually periodic. A possible route is a parity
charge that detects a difference between two shifted histories. This essay
rules out that conservation template; it does not prove nonperiodicity.

```wl
pattern = CellularAutomaton[30, {{1}, 0}, 32];
ImageResize[Image[1-pattern, "Bit"], 500, Resampling -> "Nearest"]
```

## Exploration

Preliminary exact linear algebra at widths 1–4 left only constants and spatial
coboundaries. Independent scalar checks on 5,888 finite rings matched those
spaces. These computations suggested the question and are not premises in
the theorem. One simple mixed score already fails on a uniform cyclic row:

```wl
a = ConstantArray[1, 5]; b = ConstantArray[1, 5];
afterA = Last[CellularAutomaton[30, a, 4]];
afterB = Last[CellularAutomaton[30, b, 4]];
mixedBefore = Mod[Total[MapThread[BitAnd, {a,b}]], 2];
mixedAfter = Mod[Total[MapThread[BitAnd, {afterA,afterB}]], 2];
finiteControlsPass = ({mixedBefore,mixedAfter} === {1,0});
{mixedBefore,mixedAfter,finiteControlsPass}
```

## The proof idea

Four shrinking updates admit arbitrary-length preimages with eight trailing
white cells. Varying the two outer cells independently forces an endpoint
rectangle identity for any conserved density. Subtracting a constructed
spatial potential shortens its width and preserves the conservation equation.
Induction reaches one cell, whose density is constant because every uniform
Rule 30 state becomes white. A closed-walk gradient construction supplies
the local current, and an explicit current proves the converse.

The catalog proof uses core Lean only. Finite Boolean and Fin2 identities are
checked through the kernel; they support the unbounded induction. The broader
research companion allows arbitrary additive commutative coefficient groups.
This extends the earlier scalar integer argument; no literature novelty is
claimed.

## Limits

The conserved change is exactly FOUR shrinking Rule 30 updates. The result
concerns translation-invariant finite-window parity sums over all closed
input walks. It does not exclude nonlocal invariants, nonconservative ranks,
or charges specific to a restricted canonical orbit. It implies no density
bound, absorption theorem, or solution of Problems 1, 2 or 3.
