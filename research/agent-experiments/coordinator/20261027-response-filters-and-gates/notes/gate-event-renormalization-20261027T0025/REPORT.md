# Event renormalization result

An exact parameterized return relation was obtained. The uniform gate-
halving theorem remains OPEN; no well-founded rank was proved.

For n=1+2^(4q)m with m positive odd, define
Phi(m)=4m XOR(2m OR m). Before and through first head impact,
D^t n=1 XOR2^(4q-2t)Phi^t(m), for0<=t<=2q. If q>1, the two-step update
is(q,m)->(q-1,Phi^2(m)). Thus every nontrivial gated black-head event
normalizes to gap4.

At gap4, a four-bit register driven by the ACTUAL tail R^j(m), R=D^2,
gives a precise partial first-return map. Its five permitted register
states do not form a closed finite model, since the tail is unbounded.
The white branch from the earlier paper is retained. Return to a black
head occurs through14->1 with actual tail bits a=b=1 and c OR d=1.

If the first return has tail R^J(m)=16^s*u, u odd, normalization gives
N(m)=Phi^(2s)(u), with elapsed D time2(J+s). A supplied whole2P return
guarantees existence and J+s<=P. The returned tail has exactly the SAME
bit length as m. This rules out the proposed support-length decrease
for this coordinate map; it does not rule out every possible rank.

The one inherited infinite-tail control passes: register path
1,10,10,14,1, driven by tail low-four-bit values7,14,13,11. Its gap is4
at both endpoints. Its orbit was already known; this phase only records
its expression in the induced coordinates. No new states, periods,
gaps, return paths, or finite certificates were searched.
